# 一覧の絞り込み条件のコピー / ペースト

レコード一覧画面の **「絞り込む」ダイアログ**（条件・ソートを指定するダイアログ）のタイトル部に、**⬆️（コピー）** と **⬇️（ペースト）** のアイコンが表示されます。

- **⬆️ コピー**: 現在の絞り込み条件・AND/OR・ソートを JSON としてクリップボードにコピーします。
- **⬇️ ペースト**: クリップボードの JSON を、開いている絞り込みダイアログに反映します。

別の一覧や別アプリで同じような絞り込みを再利用したいときに使えます。反映後、ダイアログの「適用」を押すと一覧に反映されます。

## JSON の形式

```json
{
  "conditions": [
    { "field": "ステータス", "operator": "次のいずれかを含む", "values": ["書類不備あり"] },
    { "field": "申請日", "operator": "=（等しい）", "dateMode": "日付を指定", "value": "2026-09-11" },
    { "field": "会社名", "operator": "次を含む", "value": "モノサス" }
  ],
  "junction": "and",
  "sort": [
    { "field": "レコード番号", "order": "昇順" }
  ]
}
```

- `conditions`: 各条件の フィールド・演算子・値。値は型により `value`（テキスト/日付）または `values`（ドロップダウン等の複数選択）。日付は `dateMode`（例: 「日付を指定」「今日」）も保持。
- `junction`: 複数条件の結合（`and` / `or`）。
- `sort`: ソート（フィールド＋昇順/降順）。複数指定可。

## 挙動と注意点

- **ペースト時は、既存の条件を「すべてクリア」してから反映します。** 同じフィールドが既に条件に含まれている場合の状態干渉を避けるためです。
- 別アプリへペーストした場合、存在しないフィールドは反映されずスキップされます。
- 演算子・日付の指定方法はダイアログのドロップダウン（Closure ウィジェット）を操作して設定します。
