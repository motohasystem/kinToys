# フィールド設定のコピー / ペースト

kintone のフォーム編集画面（`/k/admin/app/flow...`）でフィールドの設定ダイアログを開くと、タイトル部に **⬆️（コピー）** と **⬇️（ペースト）** のアイコンが表示されます。

- **⬆️ コピー**: 開いているダイアログの設定を JSON としてクリップボードにコピーします。
- **⬇️ ペースト**: クリップボードの JSON を、開いているダイアログに反映します。

同じ型のフィールド間はもちろん、共通設定は異なる型の間でも流用できます（該当するコントロールが無い設定は無視されます）。

## コピー形式（整形JSON / 1行）

オプション画面の **「フィールド設定を整形JSONでコピー」** で、コピー時の JSON 形式を切り替えられます。

- **ON（既定）**: インデント付きの整形JSON（読みやすい）
- **OFF**: 1行の JSON

どちらの形式でもペーストは可能です（ペースト時に改行を除去してから解釈するため）。

## 対応している設定

### 共通設定（多くの型で共通）
- フィールド名 / フィールドコード / フィールド名を表示しない
- 必須項目にする / 値の重複を禁止する
- 自動計算する・計算式・計算式を表示しない
- 書式・小数点以下の表示桁数・単位記号・単位の位置
- 初期値（文字列(1行) / 複数行 / リッチエディター / 数値）
- 文字数・数値の最小 / 最大、桁区切り（数値）
- 日付 / 時刻 / 日時の初期値（「登録時の日時を初期値にする」＋手動指定値）
- 選択肢（項目と順番）、項目の配置（横 / 縦）、初期選択（ラジオ / ドロップダウン / チェックボックス / 複数選択）

### フィールド型固有
- リンク: 入力値の種類（Web / 電話 / メール）
- ユーザー / 組織 / グループ選択: 複数選択の許可
- 添付ファイル: サムネイルの大きさ
- テーブル / グループ: テーブル名・フィールドコード等（共通設定でカバー）

### 関連レコード一覧
- 表示するレコードの条件（自アプリ ＝ 参照先のフィールド）
- 表示するフィールド
- レコードのソート（フィールド＋昇順 / 降順）
- さらに絞り込む条件（フィールド・演算子・値・AND / OR）
- 一度に表示する最大レコード数

### ルックアップ
- コピー元のフィールド（キー）※新規フィールド時のみ
- ほかのフィールドのコピー（コピー先 ← コピー元）
- コピー元のレコードの選択時に表示するフィールド
- 絞り込みの初期設定（フィールド・演算子・値・AND / OR）
- レコード取得時の検索方式
- ソートの初期設定

## 非対応（制限事項）

**別ダイアログ（ピッカー）を開いて値を選ぶ設定は、ペーストの自動化に対応していません。**
検索して候補から選ぶ操作を自動で駆動するのは不安定になりやすいため、意図的に対象外としています。

| 対象 | 内容 | 運用 |
|---|---|---|
| 関連レコード一覧「参照するアプリ」 | アプリ選択ピッカー | ペースト前に**手動で選択**（未選択時はアラートで案内）。コピーには表示名のみ保持 |
| ルックアップ「関連付けるアプリ」「コピー元のフィールド」 | アプリ選択ピッカー／保存後ロック | 新規フィールドで、**関連付けるアプリを手動選択後**にペースト。保存済みはこの2項目がロックされ変更不可 |
| ユーザー / 組織 / グループ選択の「初期値」 | エンティティ選択ピッカー | 非対応（手動で設定） |

### 補足
- 関連レコード / ルックアップの参照先（相手アプリ側）のフィールドは、**「参照するアプリ / 関連付けるアプリ」が選択済み**でないと候補が存在しないため反映できません。先にアプリを選択してからペーストしてください。
- 別アプリへペーストした場合、存在しないフィールドは反映されずスキップされます（エラーにはなりません）。
