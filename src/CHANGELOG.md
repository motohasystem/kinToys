# Changelog
## [0.8.0] - 2026-09-09

### Added
- フィールド設定ダイアログのコピー/ペーストを関連レコード一覧（reference_table）に対応。参照するアプリ・表示するレコードの条件・表示するフィールド・レコードのソートをJSONとしてコピー／ペーストできるように拡張（参照するアプリはアプリ選択UIの制約上、ペースト時は自動適用せず表示テキストのみ保持）
- フィールド設定ダイアログのコピー/ペーストをルックアップ（lookup）に対応。関連付けるアプリ・コピー元のフィールド・ほかのフィールドのコピー・表示するフィールド・ソートの初期設定をJSONとしてコピー／ペースト（関連付けるアプリとコピー元フィールドは保存後ロックされるため、ペーストは新規フィールドかつ関連付けるアプリを手動選択後に動作。未選択時はアラートで選択を促す）
- フィールド設定ダイアログのコピー/ペーストで、各フィールド型の共通設定に対応：初期値（文字列・数値）、文字数/数値の最小・最大、桁区切り（数値）、日付/時刻/日時の初期値（登録時の日時を初期値にする＋手動値）、項目の配置（ラジオ/チェック/複数選択）、初期選択（ラジオ/ドロップダウン/チェック/複数選択）
- フィールド設定ダイアログのコピー/ペーストで、フィールド型固有の設定に対応：リンクの入力値の種類（Web/電話/メール）、複数行文字列の初期値、リッチエディターの初期値（HTML）、ユーザー/組織/グループ選択の複数選択許可、添付ファイルのサムネイルの大きさ。テーブル/グループは既存の汎用処理（フィールド名・フィールドコード等）でカバー。なおアプリ選択・エンティティ選択など別ダイアログ（ピッカー）を開いて選ぶ設定は非対応
- 関連レコード一覧／ルックアップの残り設定に対応：関連レコードの「一度に表示する最大レコード数」、ルックアップの「レコード取得時の検索方式」、および両者の絞り込み条件（さらに絞り込む条件／絞り込みの初期設定。フィールド・演算子・値〈テキスト/日付/複数選択〉・AND/OR結合）
- フィールド設定のコピーを整形JSON（インデント付き）で行うオプションをオプション画面に追加（既定はON。OFFで従来の1行JSON）
- 一覧画面の「絞り込む」ダイアログに、絞り込み条件・AND/OR・ソート（複数可）を JSON としてコピー/ペーストする ⬆️/⬇️ アイコンを追加（ペースト時は既存条件を「すべてクリア」してから反映）

### 制限事項（フィールド設定コピー/ペーストの非対応）
別ダイアログ（ピッカー）を開いて値を選ぶ設定は、ペーストの自動化に対応していません（意図的に対象外）。詳細は [docs/field-setting-copy.md](../docs/field-setting-copy.md) を参照。
- 関連レコード一覧「参照するアプリ」: アプリ選択ピッカー。ペースト前に手動選択（未選択時はアラートで案内）
- ルックアップ「関連付けるアプリ」「コピー元のフィールド」: アプリ選択ピッカー／保存後ロック。新規フィールドでアプリ手動選択後にペースト
- ユーザー/組織/グループ選択の「初期値」エンティティ: エンティティ選択ピッカー（手動設定）

## [0.7.1] - 2026-07-22

### Fixed
- 詳細画面のテンプレートコピーで、数値・計算フィールドを画面表示どおりの文字列（桁区切り・単位の前置/後置など）で差し込むように修正

## [0.7.0] - 2026-07-14

### Added
- テンプレート管理機能を追加（並べ替え・個別削除、折りたたみ表示）
- 詳細画面でフィールドの値をクリックしてコピーする機能を追加（単体フィールド、サブテーブル、関連レコード一覧に対応）

### Changed
- テンプレートの保存先を chrome.storage.local に変更し、sync の1アイテム容量上限（QUOTA_BYTES_PER_ITEM）超過による保存エラーを解消。既存データは自動でローカルへ移行（unlimitedStorage 権限を追加）
- インポート／エクスポートをテンプレート管理内に集約
- 一覧・詳細画面のクリックコピーを document.body へのイベント委譲方式に変更し、動作を安定化

### Fixed
- セルのクリックコピーが初期表示直後に有効化されないことがある問題を修正（kintoneイベントで再バインド）
- 関連レコード一覧が初期表示ではコピーできない問題を修正
- 詳細画面フィールドのコピー時ハイライトの終端色をフィールドの背景色に合わせて調整

- 文字数や計算式など、その他の項目は順次対応予定です
