# Changelog
## [0.7.0] - 2026-07-14

### Added
- テンプレート管理機能を追加（並べ替え・個別削除、折りたたみ表示）
- 詳細画面でフィールドの値をクリックしてコピーする機能を追加（単体フィールド、サブテーブル、関連レコード一覧に対応）

### Changed
- テンプレートの保存先を chrome.storage.local に変更し、sync の1アイテム容量上限（QUOTA_BYTES_PER_ITEM）超過による保存エラーを解消。既存データは自動でローカルへ移行（unlimitedStorage 権限を追加）
- インポート／エクスポートをテンプレート管理内に集約
- 一覧・詳細画面のクリックコピーを document.body へのイベント委譲方式に変更し、動作を安定化

### Fixed
- セルのクリックコピーが初期表示直後に有効化されないことがある問題を修正（kintoneイベントで再バインド）
- 関連レコード一覧が初期表示ではコピーできない問題を修正
- 詳細画面フィールドのコピー時ハイライトの終端色をフィールドの背景色に合わせて調整

## [0.6.2] - 2026-02-11

### Added
- 多言語対応を拡張: 中国語（簡体字/繁体字）、スペイン語、ポルトガル語（ブラジル）、タイ語、ベトナム語の6言語を追加
- 言語正規化ロジックを地域コード対応に更新（zh_CN/zh_TWなどの区別に対応）

### Changed
- フィールド設定ダイアログにJSONを貼り付けるときに改行コードを事前に除去する

### Fixed
- スクロールするとツールチップが表示されなくなる問題を修正

## [0.4.6] - 2025-03-09
### Added
- アプリ設定画面のフィールド設定ダイアログの項目をコピペする機能を追加
- 現在は以下の項目に対応しています。
    - フィールド名
    - フィールドコード
    - 各種チェックボックスのON/OFF
        - フィールド名を表示しない
        - 自動計算する（一行文字列）
        - 必須項目にする
        - 値の重複を禁止する
    - ラジオボタンやチェックボックスの選択肢
- 文字数や計算式など、その他の項目は順次対応予定です
